# Security Policy

JarvisPrimez is made by **Amitanshu**.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do **not** open a public issue for security problems.
Report privately through GitHub: **Security tab -> Report a vulnerability**
(or contact the maintainer, Amitanshu, via the email on his GitHub profile).

Include a description, steps to reproduce, and the affected version.
You can expect an acknowledgement within 7 days and a fix or mitigation plan as soon as possible.

## Data and Privacy Notes

- Your **Gemini API key is stored locally** on your PC (app local storage). It is never sent anywhere except directly to Google's Gemini API.
- Never share your API key, and never commit it to GitHub. Revoke it at https://aistudio.google.com/apikey if exposed.
- While listening, microphone audio is sent to Google's Gemini API for transcription. Stop listening to stop this.
- The app has no servers, analytics or telemetry of its own.
- Download installers only from this repository's official Releases page. The installer is currently unsigned, so Windows SmartScreen may warn you.
